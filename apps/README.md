# apps

存放可直接运行的应用，前后端分离部署。

| 目录 | 说明 | 技术栈 |
| --- | --- | --- |
| [web](./web/README.md) | 前端应用 | Vue3 + Vite + TypeScript |
| [api](./api/README.md) | 后端服务 | NestJS + TypeScript |

## 约定

- 前端不直接调用模型或数据库，只通过 `api` 提供的接口通信。
- `api` 负责鉴权、限流、密钥管理，业务能力尽量下沉到 `packages/*`。
- 两个应用各自独立启动，统一在仓库根目录使用 pnpm workspace 管理依赖。
- 接口契约以 Swagger/OpenAPI 为准，前端类型尽量从契约生成或对齐。

## 开发任务清单

- [ ] 配置 pnpm workspace 与统一脚本：`dev` / `build` / `lint` / `test`
- [ ] 第 1～2 周：完成 web/api 骨架与联调（登录链路、会话与消息持久化、文件上传）
- [ ] 第 3～4 周：打通 SSE 流式聊天与工具调用链路
- [ ] 第 5～7 周：接通知识库上传、任务进度、检索问答与引用展示
- [ ] 第 8～12 周：接通 Agent 执行轨迹与人工审批回调
- [ ] 第 14 周：按环境分离配置，接入 `infra` 的容器与反向代理

## 验收标准

- [ ] 前端只通过 `api` 访问能力，代码中无直连模型或数据库
- [ ] 接口契约与 Swagger 一致，前端类型与契约对齐
- [ ] 一条命令启动前后端，跨域与鉴权链路正常
- [ ] 核心链路可端到端演示：登录 → 对话 → 知识库问答 → Agent 审批
- [ ] 模型密钥只存在于 `api` 服务端环境变量
