# apps/web

AI 全栈应用的前端，负责对话、知识库、Agent 审批等交互界面。

## 技术栈

- Vue3（Composition API）+ Vite + TypeScript
- Element Plus 组件库、Pinia 状态管理、Vue Router
- Axios 统一 API 客户端（拦截器、token 续期、错误提示）

## 规划页面

- 登录 / 注册：表单校验、JWT 存储与路由守卫
- AI Chat：多轮会话、SSE 逐 token 渲染、停止生成、重新生成
- 知识库：文档上传、解析状态、检索结果与引用展示
- Agent 工作台：执行轨迹、待审批任务（Human-in-the-loop）
- 设置：模型切换、用量与成本查看

## 约定

- 环境变量以 `VITE_` 开头，仅存放非敏感配置，模型密钥不得出现在前端。
- 所有请求经由统一的 API 客户端，避免页面内散落 `fetch` 调用。
- 流式响应用原生 `EventSource` 或 `fetch` + `ReadableStream` 实现，需处理断连与重试。

## 开发任务清单

- [ ] 工程：Vite + TS 初始化、ESLint/Prettier、路径别名、`.env.example`
- [ ] 鉴权：登录/注册、路由守卫、Pinia 用户状态、Axios 拦截器与 token 续期
- [ ] Chat：会话列表、多轮消息、SSE 逐 token 渲染、停止生成、重新生成、历史记录
- [ ] 知识库：创建知识库、批量上传、任务进度（queued/processing/success/failed）、文档列表与详情、检索调试页
- [ ] Agent：执行轨迹（节点、工具参数摘要、耗时、失败原因）、待审批任务与批准/拒绝
- [ ] 设置：模型切换、用量与成本统计页面
- [ ] 第 15 周体验优化：长对话渲染、取消请求、断线重连提示、Markdown/代码展示、空态与错误态

## 验收标准

- [ ] 未登录访问受保护路由被拦截并跳转登录；token 过期可续期或安全退出
- [ ] 流式回答逐字展示，中途可停止，停止后无残留请求
- [ ] 断网或服务异常有明确提示，恢复后可继续操作
- [ ] 上传、任务状态、分页、搜索可用，列表具备加载/空/错误态
- [ ] 引用回答可定位到文档名与页码/段落
- [ ] 审批操作有二次确认，未审批的操作不显示为已执行
- [ ] 前端构建产物中不含模型密钥
