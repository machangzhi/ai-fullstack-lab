# docs

项目文档与学习沉淀：架构、接口、复盘、面试材料。

## 内容规划

| 文件/目录 | 说明 |
| --- | --- |
| 架构图 | 系统分层、模块边界、AI 调用链路、Agent 工作流 |
| 接口文档 | OpenAPI 导出、接口契约变更记录 |
| 复盘 | 每周复盘、每日三行记录、问题与决策 |
| 评估 | Prompt / RAG / Agent 的测试集与实验结论 |
| 面试材料 | 项目介绍、技术难点、量化指标、简历素材 |

## 约定

- 架构与流程优先用图表达，文字只补充图中无法体现的约束。
- 每个关键决策记录「背景 / 选项 / 结论 / 代价」，便于面试复盘。
- 文档与代码同步更新，接口变更需同步契约文件。
- 不写入密钥、账号、内网地址等敏感信息。
