# packages/rag

企业知识库的检索增强能力：从原始文档到可被模型使用的上下文。

## 职责

- 文档解析：PDF、Word、Markdown、网页等格式的文本抽取
- 切片：按语义/长度/结构切分，保留标题层级与来源信息
- Embedding：批量向量化，失败重试与限流
- 存储与检索：pgvector 向量检索、关键词检索、混合检索
- 质量优化：重排、阈值过滤、去重、上下文裁剪
- 回答生成：引用标注、无命中时的兜底策略

## 约定

- 检索结果必须携带来源（文档 ID、页码、片段），供前端展示引用。
- 切片参数（大小、重叠）需可配置，便于做效果对比实验。
- 效果评估使用固定测试集，记录召回率与答案质量变化。
- 向量维度变更属于破坏性变更，需同步迁移脚本。

## 开发任务清单

- [ ] 解析：至少支持 PDF、DOCX、TXT、Markdown 中的三种，保留标题与页码/段落
- [ ] 切片：Recursive / Markdown splitter，输出文本、序号、来源与 token 估算
- [ ] Embedding：批量向量化（≥100 段），失败重试与限流
- [ ] 存储：pgvector 建表与索引，完成 Top-K 检索 SQL
- [x] 检索策略：Top-K、相似度阈值、Metadata Filter；混合检索离线原型与对比脚本
- [ ] 增强：可开关的 query rewrite 与 rerank
- [ ] 生成：带来源 ID 的上下文 Prompt，资料不足时拒答
- [ ] 评估：30 条问答基准集，记录 Recall@K、引用正确率、回答质量
- [ ] 清理：删除文档时同步删除 chunks 与向量

## 验收标准

- [ ] 三种以上格式可成功入库，解析结果保留可回溯的来源信息
- [ ] 任一 chunk 能定位到文档、页码/段落与原文片段
- [ ] 检索只返回用户有权限的知识库内容
- [ ] 无命中或资料不足时明确说明，不编造答案
- [ ] 删除文档后向量与 chunk 无残留，检索不再命中
- [ ] 30 条评测集有基线与改进后的指标对比记录
- [ ] 切片参数可配置，能产出对比实验结果
